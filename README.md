# Cloud-Based Hospital Management System

## Features
- Hospital dashboard
- Patient record management
- Appointment booking and status management
- REST API using Node.js + Express
- Responsive web interface
- Cloud-ready architecture

## Run locally
Install Node.js, open a terminal in this folder, then run:

npm install
npm start

If PowerShell blocks npm.ps1, use:

npm.cmd install
npm.cmd start

Open http://localhost:5000

## Cloud deployment
The project can be deployed to a cloud hosting platform such as Render, Railway or Azure App Service. For a real hospital application, add authentication, role-based access, a managed database, HTTPS, encryption, backups and proper healthcare/privacy compliance.
